Entry for the [make.fun bounty "The Robot Vacuum's Best Excuse"](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

`main.py` is a deterministic, stdlib-only program that writes one line —
a robot vacuum's deadpan excuse for missing a spot — to `/output/entry.txt`.

The line (100 characters):

> I scanned that corner three times and my map still says it's a wall. I don't argue with cartography.

Run it with:

```sh
python3 main.py
```
